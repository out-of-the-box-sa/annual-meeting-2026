# وهج اللقاء وبهجة الاحتفاء — الصفحة التعريفية للقاء السنوي 2026

صفحة ثابتة جاهزة للنشر على GitHub Pages، ولا تحتاج أي إعداد إضافي.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا من **New repository**.
2. اضغط **Add file** ثم **Upload files**، واسحب **محتويات** هذا المجلد كما هي: `index.html` ومجلد `assets` وملف `.nojekyll`. ثم اضغط **Commit changes**.
3. افتح **Settings** ثم **Pages**. من **Branch** اختر `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط بالشكل: `https://اسم-الحساب.github.io/اسم-المستودع/`

## محتويات المجلد
- `index.html`: الصفحة كاملة، مع التنسيق والتفاعلات.
- `assets/images`: الصور والشعارات وعناصر الهوية.
- `assets/fonts`: خطوط DIN Next LT Arabic.

## ملاحظات
- **الخطوط:** خطوط DIN Next LT Arabic مرخّصة. تأكد من أن ترخيص الهيئة يسمح باستضافتها على موقع ويب، خصوصًا إذا كان المستودع عامًا.
- **النماذج:** نموذج تأكيد الحضور ونموذج الأسئلة يعملان في الصفحة، لكن الردود لا تُحفظ في أي مكان حتى الآن. ربطهما بجهة استقبال (بريد إلكتروني، Google Forms، أو نظام الهيئة) خطوة لاحقة.
- **الخصوصية:** صفحات GitHub Pages في الحساب المجاني تكون عامة.
